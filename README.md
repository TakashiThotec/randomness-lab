# 「ランダム」なのに、かたまる？

10×10のマス・600点・サイコロで、感覚と確率を比べる体験教材。

**[教材を開く](https://takashithotec.github.io/randomness-lab/)**

## 内容

- コインの結果で10×10の白黒マスを作る。手元のコイン・サイコロの結果も入力可能。
- 自分で塗った図と、作り方の異なる固定の図を比較。
- 600点の比較図。Ｂの再生成、5×5の区画ごとの点の数を表示。
- 3個のサイコロで「何でもよいゾロ目」と「2・4・5（順不同）」を数える。

## 配信・更新

GitHub Pagesがmainブランチのルートを配信。index.htmlは外部依存なしの単一ファイル。操作結果を外部送信せず、Cookie・アクセス解析は使わない。

紙面掲載済みQRを維持するため、リポジトリ名・所有者・公開URLを変更しない。

## 図と生成方法

600点の初期配置は、作者の元図と同じシード2026110302および生成手順を使用。Ａは最小距離19を保つ1200点から1個おきに600点を選ぶ。Ｂは同じ範囲の独立一様な1200点から1個おきに600点を選ぶ。座標範囲は3〜997、円の半径9、描画枠1000。端の円は枠で切り取る。

scripts/generate_points.pyで座標を再現できる（Python標準ライブラリのみ）。index.html内のoriginalPointsに同じ座標を埋め込んでいる。

scripts/generate_qr.pyでQRを再生成できる（qrcode==8.2）。
